trigger: manual
description: Apply this rule whenever you are explaining an implementation plan, process, or set of technical steps where the reader needs to understand not only what to do, but also why each step is necessary
---

When explaining the implementation plan, provide detailed yet very easy-to-understand steps. For each step, clearly explain what needs to be done and why it is necessary in easy-to-understand language, so the purpose and importance of each action are very easy to understand.
